# System Fixes — Releases

Signed APKs and release notes for **System Fixes**, an LSPosed module for the ported
OxygenOS build on the Poco F7 (`onyx`).

The source repository is private; this repository only carries published builds so the
app's built-in updater can read the latest release without credentials.

## Install

1. Download `SystemFixes.apk` from the latest release.
2. Uninstall any build signed with a different key, then install this one.
3. Enable the module in LSPosed and reboot so SystemUI reloads it.

Releases older than v2.7 used a different signing key and cannot be updated in place.
